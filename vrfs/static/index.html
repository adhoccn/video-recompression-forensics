VRFS · 视频重压缩取证台

系数域（DQ 梳齿）＋ 帧大小域（GOP 相位）＋ 像素域（重编码失真残差）三条证据轴， 带适用性门控与证据强度评分，合并出一张判决卡。

先说清楚：它查什么，出的结论是什么意思

它只回答一个问题：这段 H.264 视频有没有被压缩过两次。 转码、重新压制、平台二次转码，都会留下第一代压缩的痕迹 —— 这就是它要找的东西。
✔ 能做的✘ 做不到的
· 判断有没有重压缩痕迹，并给出证据强度（0–100，不是概率）
· 已知两次压缩的 QP 时，先告诉你这个参数组合理论上测不测得出来
· 先测素材本身适不适用（门控）。不适用就直接说"不出结论"，而不是硬给一个分数
· 明确写出"无证据"和"证明没压过"是两件事 		· 不告诉你是谁改的、什么时候改的、改了什么内容
· 不是深伪 / AI 生成检测，不做人脸或画面真伪判断
· 不判版权归属、不追来源
· 只对 H.264 有效；HEVC / AV1 / VP9 的结论不可用
· CABAC 编码的 H.264 上，系数域那条轴不能用，只剩帧大小轴
· "无证据"不等于"证明只压过一次"
三种结论分别是什么意思（这句一定要读）
结论用大白话说
检出
DOUBLE_COMPRESSION_INDICATED		 找到了重压缩的证据，分数表示证据有多强（越高越强）。 这是"有证据"，不是"法律上的认定" —— 它不排除存在我们还没建模的处理方式。
无证据
NO_EVIDENCE		 三条轴都没测出东西。这可能是它真的只压过一次，也很可能是压了两次、 但正好落在理论上测不出来的参数组合上（两次 QP 相同、或相差 6 的倍数）。 要区分这两种情况，得知道两次压缩的 QP，看上方"这个操作点在理论上可检吗"。
证书不适用
NOT_APPLICABLE		 这段素材不满足方法成立的前提（比如分辨率太高、单压基线本身就远离理论模型、或是 CABAC）。 这时不给分数 —— 硬给一个数是没有依据的。
为什么"测不出来"也要单独写一种？
市面上大多数检测器只给一个分数，分数低就说是"没被改过"。但这个领域的实际情况是： 有些参数组合下，任何只看量化系数的方法都必然测不出来 —— 这是可以证明的，不是测不准。 把"测不出来"和"确实没有"混为一谈，在取证场景里会直接导致错判。 本工具宁可多写一种结论，也不把它们合并。

算法：三条轴各自在看什么，每个数是怎么算出来的

它不是"把参数拿来比一比"。每根轴都从码流里重新构造一个统计量，再配一套自己的判据； 而 r 轴是理论——先算出这个操作点在理论上测不测得出来，再让实测去和它对照。 下面四块是这套方法的全部计算过程。

① DQ 梳齿轴 — 信号源：IDR 帧的 AC 量化系数

输入：码流 → CAVLC 熵解码。需要 CAVLC/Baseline，CABAC 直接声明不可用。
  1. 解码前 13 个 IDR 帧，取 zigzag 位置 1–15 的 AC 系数绝对值（丢掉 DC）
  2. 截到 |level| ∈ 1..23，归一化为直方图 p(k)（第 24 格是尾部聚合格，必须丢）
  3. 凸峰能量 peak = Σ_k max(0, p(k) − (p(k−1)+p(k+1))/2)
  4. 单调违例 viol = Σ_k max(0, p(k+1) − p(k))
  5. score = peak + viol，与 912 组校准出的阈值 0.10 比较
为什么这样能区分：单压的 level 直方图光滑且单调递减。双压时第一代系数 c 落到第二代网格上要重新取整成 round(c·Qstep₁/Qstep₂)，多个不同的 c 会被吸到同一个 level 上 ⇒ 局部堆积成"梳齿"，并把单调性顶破。 两个统计量都无参数、对整体系数缩放不变，不需要训练。

② GOP 相位轴 — 信号源：每帧 NAL 字节数

输入：只要字节长度，不需要熵解码，因此 CABAC 上照样可用。
  1. 按起始码切出 VCL NAL，得帧大小序列，只留 P 帧
  2. 取 log，把乘性的码率波动变成加性
  3. 减去滑动中值（窗 31，远大于待测周期，免得把信号一起滤掉）
  4. 按 i mod GOP₂ 分组减组内均值 —— 陷波掉第二代自己的周期
  5. 对候选周期 p ∈ [6,25]（剔除与 GOP₂ 成整数倍的伪周期）， 算 Welch t：相位 j 的帧 vs 其余帧，取 max_j
  6. max-T 置换：把序列随机打乱 500 次，每次内部同样取 max ⇒ 得到 p 值
为什么这样能区分：第一代在 t = 0, GOP₁, 2·GOP₁ … 编 I 帧； 第二代按 GOP₂ 重编且 GOP₂ ≠ GOP₁ 时，这些位置变成 P 帧，预测结构与邻帧不同 ⇒ 新失真在周期 GOP₁ 上出现相位偏移。单压没有第一代 I 帧，该周期上就没有信号。
注意：这里不是 Bonferroni。各候选周期共用同一条序列、强正相关， Bonferroni 会过度保守；max-T 的零分布由置换本身构造，已含"取最大值"这一步， 因此不需要正态假设。

③ 适用性门控 — 不是检测器，是"这套方法在这儿成不成立"

输入：单压参考的 level 直方图。没给参考 ⇒ 门控未测，判决按"适用性未知"出具。
  1. CM 锥 = 完全单调序列锥 = 混合几何分布张成的凸锥（Hausdorff 矩问题，参数无关）
  2. 取 140 条截断几何射线作基，用 EM 求 I-投影： D = min_{q∈CM} KL(p‖q)
  3. 在单压参考上测 D_single； < 1.5e-3 才认定证书适用
为什么要这一步：理论上界只在"单压直方图贴近 CM 锥"时才成立。实测发现原生高分辨率素材 的单压直方图本身就远离锥（D 随分辨率单调上升），这时给"检出/未检出"没有依据。 门控把"能不能用"变成可测量的量，而不是按分辨率标签去猜。
关键：门控必须测在参考上，不能测在待检自己身上—— 待检若真是双压，它的 D 天然偏大，测自己就等于对每一个真阳性都拒绝出结论。

④ r 轴 — 理论：先预测这个操作点测不测得出来

输入：只需 QP₁ / QP₂ 两个整数。它不看码流，给的是可证伪的事前预测。
  1. Qstep(QP) = Q_base[QP mod 6] · 2^⌊QP/6⌋ —— QP 每 +6 步长精确翻倍 ⇒ 周期 6
  2. r = Qstep(QP₁) / Qstep(QP₂)
  3. r = 1（两次 QP 相同）⇒ 再量化幂等，DQ 轴被湮灭
  4. 1/r 恰为正整数 ⇒ 第一代网格整格落在第二代网格上， 同为精确不可检测点（QP₂ = QP₁ + 6k ⇒ 1/r = 2^k）
  5. r > 1（第二代更细）⇒ 梳齿可观测； r < 1（第二代更粗）⇒ 梳齿被大面积擦除
为什么这算算法而不是堆参数：它给出可证伪的事前预测—— 在 QP₂ = QP₁ + 6k 上，任何只看 level 直方图的方法必然静默。 实验逐点验证了这个预测，于是实测到的低分才可以被解释成"理论预期"， 而不是被当成"漏检"。没有这条理论，"无证据"就没法解释。
三根轴怎么合成一张判决卡（规则，不是加权平均）
规则内容
R0 门控门控已测且不通过 ⇒ 出 证书不适用，不给分
R1 合并码流任一轴显著 ⇒ 检出；像素域 DETECTED 与码流命中互证记 high， 静默时记 moderate（先查 r 区制，湮灭区的静默是预期）；UNDECIDABLE 表示对方分辨率不足，不是矛盾

先问一句：这个操作点在理论上可检吗？

双压缩的可检测性由 r = Qstep(QP1)/Qstep(QP2) 单点决定。 QP 每 +6 步长翻倍，所以 QP2 = QP1 + 6k 是第一代网格正好落在第二代网格上的 周期-6 不可检测点；QP1 = QP2 是幂等点，DQ 轴被完全湮灭。 在这两种点上，DQ 轴测不出东西是理论预期，不是"证明单压"。

这条扫描在验证什么
固定第一代 QP1=23，只扫第二代的 QP2。理论在扫描之前就给出每个操作点的区制： r>1 可检、r=1 幂等湮灭、1/r 为正整数是周期-6 不可检测点、r<1 擦除。 把预测与实测并排看，比单独报一个准确率有说服力 —— 因为预测说湮灭的地方分数确实 塌到 1e-3 量级，这不是拟合出来的。

反面同样重要：在幂等点与周期-6 点上码流域判 NO_EVIDENCE（无证据）， 不是判"单压"。这两件事的区别在取证里是决定性的，而市面上只给一个分数的 检测器答不了这一问。

分析

必须是同一段内容的第一代单压版本。选错了不会报错， 但门控测的就是另一段素材、像素域配对模式也会失效 —— 系统会自动识别并在结果里标出来。
已知 QP1/QP2 时，系统会先预测该操作点的区制，再与实测对照 —— 预测与实测冲突本身就是一条结论。
像素域读重编码前后的失真残差，码流域读系数直方图与帧大小 序列，两条链路互不重叠，失效的位置也不一样（见下方扫描表的实测：同一批素材上 两个方向都出现过"一边静默、另一边检出"）。取消勾选则只跑码流两轴，会更快。

    融合的价值：两条链的失效位置不一样，而且两个方向都实测到了。
    • 周期-6 不可检测点（QP2=29）：DQ 梳齿按理论湮灭（实测 1.4e-3，落在单压带）， 码流域单独跑只能说"无证据"；像素域在同一条素材上判 DETECTED（conf 0.99）。
    • 可检区（QP2=18，r=1.80）：码流域 DQ 梳齿 0.46 干净命中，像素域却判 UNDECIDABLE —— 该操作点正落在像素域的可判边界带 [1.768, 2.103] 上。
    • CABAC 高分辨率素材（内置 rde_* 样例）：系数轴直接不可用，像素域判 DETECTED。
    由此得出的一条口径，务必按这个读：周期-6 不可检测点 说的是DQ 梳齿这一条轴（系数域网格对齐导致梳齿湮灭）， 不是"任何方法都检不出"。像素域不看系数网格，所以它不受这条约束。 把它写成"该操作点不可检测"而不限定轴，是对该理论最常见的误读。

    素材要求与结果怎么读

    项要求 / 说明
    编码H.264。DQ 轴需要 CAVLC（Baseline，-coder cavlc）； CABAC 码流该轴返回 unavailable，此时只剩 GOP 轴。HEVC/AV1/VP9 结论不可信。
    长度DQ 轴读前 13 个 IDR 帧；GOP 轴需要 ≥60 个 VCL 帧。20–60 秒足够。
    大小建议单文件 ≤100 MB。纯码流解析，不解码像素，不吃显存。
    参考同内容、同起点、同时长的单压版本。给参考 = 开门控；不给 = 门控未测， 判决会标注"适用性未知"。
    三种判决DOUBLE_COMPRESSION_INDICATED 检出； NO_EVIDENCE 无证据（≠ 证明单压）； NOT_APPLICABLE 证书不适用，不给分数。
    为什么要有门控（与只给分数的检测器的区别）
    理论的可检测性上界只在"单压基线贴近完全单调锥"时成立。实测发现原生高分辨率素材的 单压直方图本身就远离锥（D_single 随分辨率单调上升）。在那种素材上硬给一个分数是 没有依据的。门控把这件事变成一个可测量的量：先测参考的 D_single，超过阈值就 直接输出"证书不适用"，而不是靠分辨率标签猜。司法场景里这决定报告能不能用。
